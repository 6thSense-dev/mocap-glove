Coils & hand IMU

Connect hub

Run one coil first. Bursts stop automatically after at most 100 ms, with a two-second cooldown. Unselected axes coast. These are bench tests, not continuous tracking.

Current guard: 125 mA per selected axis, 25 mA on unselected axes; readings are sampled, not a verified hardware current limit. Check the scope waveform. Never attach a grounded scope clip to either coil terminal.

First coil test with your scope

Use the X coil connector pins 1–2. Measure its resistance with USB disconnected. Connect scope grounds to board GND only; use two channels and CH1−CH2 to measure across the coil. Start with a 10 ms burst and single-shot trigger. Expected X drive frequency is 4.5 kHz. The current monitor signal is centred near half the sensing supply, with 4 V/A sensitivity. Zero current does not prove the coil is working.

Connection and recovery help

If the hub is missing, use a data-capable USB cable and press RESET with BOOT released. Close other serial consoles, then rescan. BOOT mode is only for flashing; it will not appear as a control-panel device.

Disconnect USB before attaching or moving flex cables. Closing this panel stops its heartbeat; after 45 seconds the server requests sensor power off and closes USB. Use “Power off sensors” for an immediate request. If USB communication fails, unplug the hub.

Restart resets the hub and disconnects this panel. Reconnect afterward. Firmware flashing remains a separate operation using the verified flashing helper.
