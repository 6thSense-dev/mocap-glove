# V6 PCB design archive

Complete current V6 project files for the hand hub, fingertip flex board and source carrier. Open each folder's `.kicad_pro` in KiCad 9. Custom symbols, footprints and envelope models are included; standard 3D models require KiCad's standard model library.

Each board includes schematics, routed PCB, project settings, local libraries, BOM, placement CSV, Gerber/drill files and ZIP, fabrication notes, rendered views and historical ERC/DRC reports. Source-carrier is included as a design artifact; it is not proof of the current hand-wound coil assembly configuration.

This is an archive of the existing V6 design, not a new engineering release or a renewed validation. Historical notes and reports reflect their original dates. In particular, the fingertip fabrication data specifies 0.40 mm FR4 stiffening; confirm the manufacturer-approved stackup before reordering. Do not infer measured tracking accuracy or factory acceptance from these files.

Order/checkout records, private contact details, editor state, obsolete V1–V5 designs and software recordings are excluded. Only machine-specific paths in exported verification netlists were made relative; electrical design and manufacturing files are unchanged. FILE-MANIFEST.json records SHA-256 hashes of the published files.
